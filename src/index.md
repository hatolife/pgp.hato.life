# PGPについて

ここでは [PGP](https://ja.wikipedia.org/wiki/GNU_Privacy_Guard) について簡単に解説します。

主に、データが改竄されていないことの確認に使用します。

## PGPでできること

- 配布されたファイルが途中で改竄されていないか確認できます。
- そのファイルが、公開鍵を持っている相手によって署名されたものか確認できます。
- メールやファイルを暗号化できます。
- Gitのコミットやリリースファイルの署名確認にも使われます。

このサイトでは、暗号化ではなく **実行ファイルの署名確認** に絞って説明します。

## 詳しい説明

PGPでは、署名する人が秘密鍵を使って署名を作ります。
確認する人は、対応する公開鍵を使って署名を確認します。

配布ファイルでは、次の2つがセットで置かれることがあります。

- `example.exe`: 実行ファイル本体
- `example.exe.asc`: 署名ファイル

確認する側は、公開鍵を取得し、`.asc` を使って本体ファイルが改竄されていないか確認します。
公開鍵は名前だけで判断せず、Fingerprintが一致しているか確認します。

Windowsでは、この確認にKleopatraを使うのがわかりやすいです。
