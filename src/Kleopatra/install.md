# Gpg4winを取得してインストールする

結論: ここからダウンロードできます。

[Gpg4winをダウンロードする](https://www.gpg4win.org/thanks-for-download.html)

Gpg4winを入れると、Kleopatraも一緒に入ります。
通常のダウンロード案内ページは寄付ボタンが目立つため、上のリンクを使うと迷いにくいです。

2026年6月22日時点では、上のページから Gpg4win 5.0.2 のインストーラーへ進みます。
バージョン番号は更新されることがあります。

## インストールする

1. インストーラーを開きます。
2. 迷ったら既定の選択のまま進めます。
3. コンポーネント選択では、Kleopatraを含めます。
4. インストーラーは英語でわかりにくいですが、インストール後のKleopatraは日本語で使用できます。
5. インストール後、スタートメニューから `Kleopatra` を開きます。

## 使う

結論: 署名確認だけなら、自分の鍵を作る必要はありません。

1. 確認したい配布元の公開鍵を取得します。
2. 公開鍵の `.asc` ファイルをKleopatraへドラッグ&ドロップしてインポートします。
3. 本体ファイルと署名ファイルを同じフォルダーに置きます。
4. 署名ファイル、たとえば `example.exe.asc` をKleopatraへドラッグ&ドロップします。
5. 表示されたFingerprintと結果を確認します。

赤いエラー、`Bad`、`Invalid signature` が出た場合は、そのファイルを実行しないでください。

次は [実行ファイルのPGP署名を確認する](./index.md) に進んでください。
