# Gpg4winを取得してインストールする

WindowsでKleopatraを使う場合は、Gpg4winをインストールします。
KleopatraはGpg4winに含まれています。

## 取得する

1. ブラウザで [Gpg4win公式ダウンロードページ](https://www.gpg4win.org/download.html) を開きます。
2. `Gpg4win` の最新版をダウンロードします。
3. ダウンロードしたインストーラーを実行します。

2026年6月22日時点で、公式ダウンロードページには Gpg4win 5.0.2 が掲載されています。
ページ上のバージョン番号は更新されることがあります。

## インストールする

1. インストーラーを開きます。
2. Windowsの確認画面が出たら、発行元やファイル名を確認して進めます。
3. コンポーネント選択では、Kleopatraを含めます。
4. 迷った場合は、既定の選択のまま進めます。
5. インストール後、スタートメニューから `Kleopatra` を開きます。

## 使う

署名確認だけなら、最初に自分の鍵を作る必要はありません。

1. 確認したい配布元の公開鍵を取得します。
2. 公開鍵の `.asc` ファイルをKleopatraへドラッグ&ドロップしてインポートします。
3. 本体ファイルと署名ファイルを同じフォルダーに置きます。
4. 署名ファイル、たとえば `example.exe.asc` をKleopatraへドラッグ&ドロップします。
5. 表示されたFingerprintと結果を確認します。

赤いエラー、`Bad`、`Invalid signature` が出た場合は、そのファイルを実行しないでください。

次は [Kleopatraで署名を確認する](./index.md) に進んでください。
